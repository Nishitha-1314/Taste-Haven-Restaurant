# 🍽️ TASTE HAVEN – Restaurant Website

**Taste Haven** is a modern and attractive restaurant website designed to provide customers with a delightful digital dining experience. It showcases delicious food collections, restaurant details and an elegant interface that makes exploring the restaurant easy and enjoyable.

## ✨ Features

- 🏠 **Home Page** – Attractive landing page with restaurant branding.
- 🍕 **Food Menu** – Displays delicious food items and menu collections.
- 🥗 **Food Categories** – Organized food sections for easy browsing.
- 📸 **Food Gallery** – Beautiful food images and restaurant visuals.
- 👨‍🍳 **About Us** – Information about the restaurant and its services.
- 📞 **Contact Section** – Provides restaurant contact information.
- 🎨 **Modern UI Design** – Attractive colors, layouts and typography.
- 📱 **Responsive Design** – User-friendly layout for different screen sizes.
- ✨ **Smooth Navigation** – Easy movement between website sections.

## 🛠️ Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layouts and visual presentation.
- JavaScript – Interactive website functionality (if implemented).

## 🎯 Project Objective

The main objective of Taste Haven is to create a digital platform for a restaurant where customers can explore food menus, learn about the restaurant and access important information easily.

This project demonstrates practical knowledge of web development, webpage designing, styling and user interface development.
